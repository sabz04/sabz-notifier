# sabz-notifier

Уведомления о новых сообщениях **Avito** и **VK** в Telegram — чтобы ничего не потерять.

Шлёт только то, что написал **живой человек**: поддержка Авито, промо, доставка,
сообщества ВК, системные события чата («посмотрел номер», «создал чат») и твои
собственные исходящие — отсекаются. Первый опрос запоминает текущее состояние
молча, так что старые непрочитанные не прилетят пачкой.

## Быстрый старт на VPS

```bash
git clone <репозиторий> sabz-notifier && cd sabz-notifier
sudo ./install.sh
```

Скрипт спросит токен и username, поставит зависимости, создаст пользователя и
службу systemd, при нехватке памяти добавит swap, проверит себя и запустится.
Всё повторяемо — можно гонять сколько угодно раз.

Без вопросов:

```bash
sudo ./install.sh --token 123456:AA... --owner sabzrr --mode light -y
```

Дальше напиши боту в Telegram `/start` — он запомнит твой чат.

### Что делает install.sh

- ставит системные пакеты, при нехватке памяти создаёт swap 2 ГБ и прописывает его в fstab;
- заводит служебного пользователя `sabz` и каталог `/opt/sabz-notifier`;
- пишет `.env` с правами `640 root:sabz` — токен не виден посторонним;
- ставит юнит systemd с лимитами памяти и CPU, автозапуском и перезапуском при падении;
- в режиме `browser` — поднимает отдельный venv (системный python не трогает),
  ставит Chromium **вместе с системными библиотеками** и проверяет, что браузер
  реально запускается, а не просто скачался;
- прогоняет самопроверку и стартует службу.

Запускать можно сколько угодно раз — скрипт идемпотентный и подхватывает уже
введённый токен из установленного `.env`.

## Два режима

| | `light` (по умолчанию) | `browser` |
|---|---|---|
| Память | ~25 МБ | ~700–1200 МБ |
| Нужен браузер | нет | да, Chromium |
| Как даёшь доступ | присылаешь боту cURL в Telegram | логинишься один раз в окне браузера |
| Когда протухнет | пришлёшь новый cURL (бот сам попросит) | обычно не протухает |
| Требования | любой VPS | от 2 ГБ RAM |

### light — как дать доступ

Открой мессенджер в обычном браузере, `F12 → Network`, правой кнопкой по нужному
запросу → `Copy → Copy as cURL (bash)`. Потом боту:

- `/avito` и следующим сообщением вставь cURL страницы мессенджера
- `/vk` и вставь cURL запроса к API либо токен

Бот сам поймёт и JSON, и HTML, проверит доступ и скажет, сколько чатов видит.

### browser — как войти

```bash
sudo sabz-notifier login
```

Поднимет браузер на сервере и покажет команду SSH-туннеля. Открываешь
`http://localhost:6080/vnc.html` у себя, логинишься в Авито и ВК — и всё.
Наружу порт не торчит, только через твой туннель.

## Управление

```bash
sabz-notifier status      # состояние + самопроверка
sabz-notifier logs -f     # логи вживую
sabz-notifier restart
sabz-notifier config      # настройки, токен скрыт
sudo ./install.sh --uninstall
```

## Команды бота в Telegram

```
/status          что настроено и живо ли
/interval 25     период опроса, секунды
/ignore слово    не слать, если слово есть в имени или тексте
/ignore          показать список; /ignore- слово — убрать
/mute /unmute    тишина
/test            проверить связь
/login           (browser) открыть Авито и ВК для входа
/proxy avito ... (light) HTTP-прокси для Авито
```

Управлять ботом может только владелец из `TG_OWNER` — остальные молча игнорируются.

## Что важно знать

**Авито проверяет незнакомые IP.** С VPS (особенно вне РФ) Авито отдаёт
`HTTP 429 «Доступ ограничен: проблема с IP»` — это не глухой бан, а проверка
«подтвердите, что вы не робот» с кнопкой. Её проходит человек, бот этого не
делает и не должен.

Главное: **проверку нужно пройти с того же IP, с которого ходит бот.** Сделать
это в домашнем браузере бесполезно — клирэнс привязан к адресу. На сервере это
значит режим `browser` и:

```bash
sudo sabz-notifier login
```

Открываешь через SSH-туннель, жмёшь кнопку — клирэнс ложится в куки профиля
бота, и он работает дальше сам.

Бот распознаёт эту страницу и **сразу пишет тебе в Telegram**, что нужно зайти
и пройти проверку, а когда она пройдена — сообщает, что продолжил. Повторные
напоминания приходят не чаще раза в час, проверяет он каждые 5 минут.

Альтернатива — выпускать запросы Авито через российский HTTP-прокси:

```
/proxy avito http://user:pass@host:port
```

ВК с зарубежных адресов работает нормально и проверок не требует.

**Один токен — один бот.** Telegram отдаёт `409`, если два экземпляра тянут
обновления одним токеном. Прежде чем запускать на сервере, останови бота на
другой машине.

**Разбор опирается на вёрстку Авито и ВК.** Если они переверстают страницы,
бот не упадёт — просто притихнет и напишет о проблеме, а селекторы надо будет
поправить.

## Windows (десктоп)

Тот же `bot.py`, запуск через `run.pyw` без окна консоли, настройки в `.env`
рядом (см. `.env.example`), автозапуск — задача Планировщика. Для браузерного
режима используется системный Chrome с отдельным профилем в `data/browser`,
основной профиль не трогается.

## Файлы

```
bot.py           весь бот (stdlib; playwright только для режима browser)
install.sh       установка и удаление на VPS
sabzctl          команда sabz-notifier
run.pyw          запуск на Windows без консоли
.env.example     образец настроек
```

Состояние и куки живут в `data/` и в git не попадают.
