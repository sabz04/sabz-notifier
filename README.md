# sabz-notifier

Уведомления о новых сообщениях **Avito** и **VK** в Telegram — чтобы ничего не потерять.

Шлёт только то, что написал **живой человек**: поддержка Авито, промо, доставка,
сообщества ВК, системные события чата («посмотрел номер», «создал чат») и твои
собственные исходящие — отсекаются. Первый опрос запоминает текущее состояние
молча, так что старые непрочитанные не прилетят пачкой.

Доставать cURL, куки и токены не нужно: бот держит собственный браузер, ты
логинишься в нём один раз.

---

## Установка

Выбери свой вариант. Все три спрашивают одно и то же: токен бота, кто им
управляет и кому слать уведомления.

### 🖥 Сервер — Linux (VPS), круглосуточно

```bash
curl -fsSL https://raw.githubusercontent.com/sabz04/sabz-notifier/vps/install.sh | sudo bash
```

Ставит службу systemd, при нехватке памяти добавляет swap. Экрана на сервере
нет, поэтому браузер живёт на виртуальном экране, а для входа в аккаунты бот
присылает в Telegram ссылку — открываешь её и логинишься.

### 🍎 macOS — локально

```bash
curl -fsSL https://raw.githubusercontent.com/sabz04/sabz-notifier/vps/install-mac.sh | bash
```

**Без `sudo`** — бот работает от твоего пользователя, иначе он не увидит экран.
Ставит автозапуск через launchd. Окно браузера появится прямо на рабочем столе,
там и логинишься.

Нужен `python3`: если его нет, macOS сама предложит поставить инструменты
разработчика, либо выполни `xcode-select --install`.

### 🪟 Windows — локально

Скачай [**install-windows.bat**](https://raw.githubusercontent.com/sabz04/sabz-notifier/vps/install-windows.bat)
и запусти двойным кликом. Права администратора не нужны.

Ставит автозапуск через Планировщик задач. Окно браузера появится на рабочем
столе, там и логинишься.

Нужен [python.org](https://www.python.org/downloads/) с галочкой
**Add Python to PATH** при установке.

Удалить: `install-windows.bat uninstall` (данные останутся) или
`install-windows.bat purge` (вместе с данными).

## После установки

1. Напиши боту в Telegram **`/start`**
2. Залогинься в Авито и ВК в окне браузера, которое откроет бот

Всё. Дальше он работает сам.

> **Владелец — это твой аккаунт в Telegram, а не имя бота.** Если вписать сюда
> `@имя_бота`, бот перестанет слушаться. Установщик такую ошибку ловит сразу.

> **Получатель должен сам написать боту `/start`** — Telegram не разрешает ботам
> писать первыми.

## Команды бота в Telegram

```
/status          что настроено и живо ли
/settings        все настройки и как их менять
/recipient @name кому слать уведомления; /recipient - — снова себе
/interval 40     период опроса, секунды
/ignore слово    не слать, если слово есть в имени или тексте
/mute /unmute    тишина
/restart         перезапустить бота
/login           войти в Авито и ВК
/avito, /vk      состояние источника
/avito off       выключить источник, /avito on — включить обратно
```

Источники независимы: если Авито на твоём адресе закрыт, выключи его командой
`/avito off` — ВК продолжит работать, и бот перестанет напоминать о проблеме.

Управлять ботом может только владелец из `TG_OWNER`. Команда от кого-то ещё
получит вежливый ответ, что владелец другой, и подсказку, как это исправить.

## Управление на сервере (Linux)

```bash
sabz-notifier
```

Откроется меню: статус и самопроверка, логи, перезапуск, настройки, вход в
аккаунты, удаление. Есть и прямые команды — `status`, `logs -f`, `restart`,
`config`, `reconfigure`, `login`, `uninstall [--full]`.

Поменять настройку и перезапустить:

```bash
sudo sabz-notifier config recipient @sabzrr
```

## Управление на macOS

```bash
tail -f ~/.sabz-notifier/bot.log                                  # логи
launchctl unload -w ~/Library/LaunchAgents/com.sabz.notifier.plist  # остановить
launchctl load  -w ~/Library/LaunchAgents/com.sabz.notifier.plist   # запустить
./install-mac.sh --uninstall                                      # удалить
```

Остальное — из Telegram, командой `/settings`.

## Обновление

Та же команда, что и установка. Скрипт остановит работающий экземпляр, положит
свежий код поверх и запустит заново. Настройки, куки и профиль браузера
сохраняются, токен подхватывается из прошлой установки. Нужна переустановка
совсем с нуля — добавь `--fresh`.

## Что важно знать

**Авито закрывает доступ хостингам.** Это главное ограничение, и оно не про
софт. С адресов дата-центров Авито отдаёт `HTTP 429 «Доступ ограничен: проблема
с IP»` — сразу, ещё до логина: главная не открывается даже без единой куки.
Проверить адрес до установки:

```bash
curl -s -o /dev/null -w "%{http_code}\n" -A "Mozilla/5.0" https://www.avito.ru/
```

`200` — адрес пускают, `429` — закрыт, и никакие куки, капчи и настройки этого
не изменят.

- **Домашний (резидентный) адрес работает надёжно** — Mac, ПК, мини-сервер.
  Там Авито обычно даже капчу не спрашивает.
- **Российский VPS** — шансы выше зарубежного, но это по-прежнему хостинг.
  Проверяй командой выше.
- **Зарубежный VPS** — почти гарантированно `429`.

**ВК таких ограничений не имеет** и работает с любого адреса.

**Один токен — один бот.** Telegram отдаёт `409`, если два экземпляра тянут
обновления одним токеном. Прежде чем запускать на новой машине, останови старую.

**Разбор опирается на вёрстку Авито и ВК.** Если они переверстают страницы, бот
не упадёт — притихнет и напишет о проблеме, а селекторы надо будет поправить.
