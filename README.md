# sabz-notifier

Уведомления о новых сообщениях **Avito** и **VK** в Telegram — чтобы ничего не потерять.

Шлёт только то, что написал **живой человек**: поддержка Авито, промо, доставка,
сообщества ВК, системные события чата («посмотрел номер», «создал чат») и твои
собственные исходящие — отсекаются. Первый опрос запоминает текущее состояние
молча, так что старые непрочитанные не прилетят пачкой.

## Установка одной командой

```bash
curl -fsSL https://raw.githubusercontent.com/sabz04/sabz-notifier/vps/install.sh | sudo bash
```

Клонировать ничего не надо — скрипт сам скачает всё, что нужно. Он спросит три вещи:

1. **Токен бота** — берётся у [@BotFather](https://t.me/BotFather)
2. **Кто управляет ботом** — `@username` или числовой id
3. **Кому слать уведомления** — `@username`, `@канал` или id; с `@` и без. Enter — себе

> **Владелец — это твой аккаунт в Telegram, а не имя бота.** Если вписать сюда
> `@имя_бота`, бот перестанет слушаться. Установщик такую ошибку ловит сразу.

Дальше он всё делает сам: ставит зависимости, при нехватке памяти добавляет swap,
заводит пользователя и службу systemd, скачивает браузер, проверяет его запуском
и запускается. В конце сразу предложит войти в Авито и ВК.

## Вход в аккаунты

Доставать cURL, куки и токены **не нужно** — бот держит собственный браузер, и ты
просто логинишься в нём один раз. В конце установки (или командой
`sudo sabz-notifier login`) он поднимет браузер и напечатает ссылку вида:

```
http://ВАШ_IP:6080/vnc.html?autoconnect=true&password=XXXXXXXX
```

Открываешь её в обычном браузере — видишь рабочий стол сервера с двумя вкладками,
Авито и ВК. Логинишься в обеих, там же жмёшь кнопку проверки «я не робот», если
Авито попросит. Возвращаешься в терминал, `Ctrl+C` — доступ закрывается, бот
поднимается сам.

Никаких SSH-туннелей и второго терминала. Пароль одноразовый, генерируется на
каждый вход, порт открыт **только** пока идёт вход и закрывается сам через
30 минут.

Куки живут в профиле бота и продлеваются сами — повторно логиниться не нужно.
Если сессия всё же слетит, бот напишет об этом в Telegram.

## Управление

```bash
sabz-notifier
```

Откроется меню: статус и самопроверка, логи вживую, перезапуск, настройки, вход
в аккаунты, удаление. Для скриптов есть и прямые команды — `status`, `logs -f`,
`restart`, `config`, `reconfigure`, `login`, `uninstall`.

## Изменить настройки

Посмотреть (токен скрыт):

```bash
sabz-notifier config
```

Поменять один параметр — бот перезапустится сам:

```bash
sudo sabz-notifier config recipient @sabzrr
```

Ключи: `token`, `owner`, `recipient`. Переспросить всё заново:

```bash
sudo sabz-notifier reconfigure
```

Часть настроек меняется **прямо из Telegram**, без захода на сервер:

```
/settings         все настройки и что из них можно менять
/recipient @name  кому слать уведомления (/recipient - — снова себе)
/interval 40      как часто проверять
/ignore слово     что не присылать
/mute /unmute     тишина
/restart          перезапустить бота
/login            открыть Авито и ВК для входа (пришлёт ссылку)
/status           что настроено и живо ли
/avito, /vk       состояние источника
/avito off        выключить источник, /avito on — включить обратно
```

Источники независимы: если Авито на твоём адресе закрыт, выключи его командой
`/avito off` — ВК продолжит работать, и бот перестанет напоминать о проблеме.

Управлять ботом может только владелец из `TG_OWNER` — команда от кого-то ещё
получит вежливый ответ, что владелец другой, и подсказку, как это исправить.

## Обновление

Та же команда, что и установка. Скрипт остановит работающий экземпляр, положит
свежий код поверх и запустит заново. Настройки, куки и профиль браузера
сохраняются, токен подхватывается из прошлой установки. Нужна переустановка
совсем с нуля, вместе с данными — добавь `--fresh`.

## Удалить

Убрать бота, но сохранить данные:

```bash
sudo sabz-notifier uninstall
```

Снести подчистую — данные, профиль, скачанный браузер, служебного пользователя и
swap, который создавал установщик:

```bash
sudo sabz-notifier uninstall --full
```

То же из папки репозитория: `sudo ./install.sh --uninstall` и `--purge`.

Системные пакеты не трогаются даже при полном удалении — их могли ставить не мы,
и от них могут зависеть другие сервисы на машине.

## Что важно знать

**Авито закрывает доступ хостингам.** Это главное ограничение, и оно не про
софт. С адресов дата-центров Авито отдаёт `HTTP 429 «Доступ ограничен: проблема
с IP»` — причём сразу, ещё до всякого логина: главная страница не открывается
даже без единой куки. Проверить свой сервер можно так:

```bash
curl -s -o /dev/null -w "%{http_code}\n" -A "Mozilla/5.0" https://www.avito.ru/
```

`200` — адрес пускают, `429` — закрыт, и никакие куки, капчи и настройки этого
не изменят.

Что с этим делать:

- **Домашний (резидентный) адрес работает надёжно** — свой ПК, мини-сервер,
  Raspberry Pi. Там Авито обычно даже капчу не спрашивает.
- **Российский VPS** — шансы заметно выше зарубежного, но это по-прежнему
  хостинг, и часть диапазонов тоже закрыта. Проверяй командой выше до установки.
- **Зарубежный VPS** — почти гарантированно `429`.

Если адрес пускают, но иногда выскакивает проверка «подтвердите, что вы не
робот» — её проходит человек: бот пишет об этом в Telegram, ты шлёшь `/login`,
жмёшь кнопку в открывшемся окне. Проходить надо **с того же адреса, откуда ходит
бот**.

**ВК таких ограничений не имеет** и работает с любого адреса. Если Авито на
твоей машине закрыт — просто выключи его и пользуйся ВК:

```
/avito off
```

**Один токен — один бот.** Telegram отдаёт `409`, если два экземпляра тянут
обновления одним токеном. Прежде чем запускать на сервере, останови бота на
другой машине.

**Получатель должен сам написать боту `/start`.** Telegram не разрешает ботам
писать первыми.

**Разбор опирается на вёрстку Авито и ВК.** Если они переверстают страницы, бот
не упадёт — притихнет и напишет о проблеме, а селекторы надо будет поправить.

## Требования

Ubuntu/Debian, root, от ~1 ГБ RAM (установщик сам добавит swap) и ~1 ГБ на диске
под браузер.

## Windows (десктоп)

Тот же `bot.py`, запуск через `run.pyw` без окна консоли, настройки в `.env`
рядом (см. `.env.example`), автозапуск — задача Планировщика. Используется
системный Chrome с отдельным профилем в `data/browser`, основной профиль не
трогается.

## Файлы

```
bot.py           весь бот (stdlib + playwright)
install.sh       установка, обновление и удаление
sabzctl          команда sabz-notifier с меню
run.pyw          запуск на Windows без консоли
.env.example     образец настроек
```

Состояние и куки живут в `data/` и в git не попадают.
